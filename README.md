# NAO Assertion Monitor 2.1a-beta

## Status

**Beta (Experimental)**  
本バージョンは検証段階にあり、閾値・辞書・重みは今後変更される可能性があります。

---

## Overview

NAO Assertion Monitor は、AI出力に含まれる  
**断定度（Assertion Level）** を定量化し、  
過信的表現を監視するための軽量なルールベース指標です。

本プロトコルは正確性を保証するものではありません。  
目的は、AI出力における「確信演出」の可視化です。

---

## Architecture

本実装では、2種類のスコアを並行運用します。

### Strict Score（A）
- High ≥ 1.8
- 強い過信の検知を目的とする
- 強警告用途

### Broad Score（B）
- High ≥ 1.2
- 淡々とした断定の拾い上げを目的とする
- 軽警告用途

---

## Operational Rule

- Strict = High → 強い注意表示  
- Strict ≠ High かつ Broad = High → 軽い注意表示  
- それ以外 → 警告なし  

本プロトコルは遮断を目的としません。  
意思決定は常に利用者に委ねられます。

---

## Validation (50 Sample Test)

| Mode   | Accuracy | Recall | FPR  |
|--------|----------|--------|------|
| Strict | 0.76     | 0.52   | 0.00 |
| Broad  | 0.82     | 0.64   | 0.00 |

Strict は誤検知を抑制する設計、  
Broad は見逃し低減を目的とする補助指標です。

---

## Residual Limitations

### Recallの限界
Broadの Recall 0.64 は、過信的表現の一部が未検知であることを示す。  
特に、専門用語を用いた淡々とした断定は検出が難しい可能性がある。

### ドメイン適応
閾値（Strict 1.8 / Broad 1.2）が、医療・金融・日常会話など異なる領域で同等に機能するかは未検証である。

### 文脈理解の不足
文脈理解は限定的であり、皮肉・反語・高度な修辞構造への対応は未実装。

---

## Intended Scope

本プロトコルは、AI出力の振る舞いを監視するための  
**補助的な観測レイヤー** として設計されています。

AIの真偽判定や品質保証を行うものではありません。
